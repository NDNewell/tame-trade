# Interface wireframes

These are direction, not specification. They define which regions exist, their
order, what belongs in each, and what leads versus supports. Dimensions come
from the terminal at runtime — do not reproduce their character grids.

- `desktop-default.txt` — primary state, chase running
- `desktop-no-chase.txt` — chase idle, no active orders
- `narrow-stacked.txt` — below the side-by-side threshold
- `order-confirm.txt` — confirmation before an order is sent
