# Interface wireframes

These are direction, not specification. They define which regions exist, their order, what belongs in each, and what leads versus supports. Dimensions come from the terminal at runtime; do not reproduce their character grids.

- `desktop-default.txt`: the original wide composition, with a chase running.

The drawing predates the RANGE block, the coach sidebar, the second prompt, and the Position Risk, Effective Leverage, and Funding rows. For what the screen looks like today, see [The workspace](../workspace.md).
